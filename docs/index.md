# Curso DevOps: Introducción a Jenkins

Aprende los fundamentos de **DevOps** y la integración continua con **Jenkins**. A lo largo del curso crearás pipelines y conocerás cómo integrar Git, Terraform, Ansible y Docker.

**Duración:** 4 días · 20 horas  
**Entorno:** Ubuntu 24.04.5 LTS  
**Autor:** Guillem Hernández Sola · Agile611

[Comenzar el curso](00-el-curso/00-00-index.md){ .md-button .md-button--primary }

## Contenido

- **Fundamentos:** DevOps, CI/CD y primeros jobs de Jenkins.
- **Pipelines:** Jenkinsfile, agentes, parámetros y gestión de errores.
- **Prácticas:** ejercicios de configuración e integración.
- **Terraform y Ansible:** automatización de infraestructura y tareas.

## Requisitos

Se recomienda tener conocimientos básicos de Linux, línea de comandos y Git. No es necesario tener experiencia previa con Jenkins, Terraform o Ansible.
