# Requisitos previos

El curso se desarrolla sobre **Ubuntu 24.04.5 LTS** y combina explicaciones con ejercicios prácticos de DevOps, Jenkins y automatización. No es necesario tener experiencia previa con Jenkins, Terraform o Ansible, pero sí conviene contar con algunos conocimientos básicos para seguir los ejemplos con comodidad.

---

## Conocimientos recomendados

Antes de empezar, es útil tener familiaridad con los siguientes temas:

- **Línea de comandos:** ejecutar comandos, desplazarse entre directorios y gestionar archivos.
- **Administración básica de sistemas:** nociones generales sobre usuarios, permisos y procesos en Linux o Windows.
- **Git:** clonar un repositorio, consultar cambios y entender el propósito de las ramas y los commits.
- **Desarrollo de software:** comprender de forma general qué son el código fuente, las pruebas y una aplicación.
- **YAML:** reconocer su estructura básica, especialmente la indentación y las parejas clave-valor.

!!! tip "No necesitas ser especialista"
    Estos conocimientos se consideran una base de partida, no un examen de admisión. Los conceptos se irán explicando conforme aparezcan en el curso.

---

## Entorno de trabajo

Las prácticas están preparadas para realizarse en un entorno basado en **Ubuntu 24.04.5 LTS**. Para seguirlas, necesitarás:

- Acceso a una máquina virtual, servidor o equipo con Ubuntu 24.04.5 LTS.
- Una cuenta de usuario con permisos para ejecutar las tareas indicadas en las prácticas.
- Acceso a la terminal de Ubuntu.
- Conexión a Internet para descargar herramientas, consultar documentación y acceder a repositorios.
- Un navegador web para utilizar la interfaz de Jenkins y los servicios relacionados.
- Acceso a GitHub o al repositorio de código utilizado durante los ejercicios.

Algunas prácticas de instalación o configuración pueden requerir permisos de administración mediante `sudo`. Utiliza esos permisos solo cuando los pasos del ejercicio los indiquen.

!!! warning "Entorno de pruebas"
    Realiza las prácticas en un entorno de laboratorio o de desarrollo. No ejecutes cambios de infraestructura ni pruebas experimentales en sistemas de producción sin autorización y sin revisar sus posibles efectos.

---

## Conocimientos opcionales

No son imprescindibles para empezar, pero pueden ayudarte en algunos módulos:

- **Docker:** conceptos básicos de imágenes y contenedores.
- **SSH:** conexión remota y autenticación entre equipos.
- **Terraform:** nociones de infraestructura como código.
- **Ansible:** conceptos básicos de automatización mediante playbooks.
- **Jenkins:** familiaridad previa con jobs, agentes o pipelines.

El curso introduce estas herramientas progresivamente y las utiliza en ejemplos prácticos.

---

## Lo que no necesitas

Para comenzar el curso, **no hace falta**:

- Haber instalado o administrado Jenkins anteriormente.
- Dominar Terraform o Ansible.
- Tener experiencia profesional en DevOps.
- Conocer todos los detalles de administración de Ubuntu.

El objetivo es construir una base práctica paso a paso y comprender cómo se relacionan Jenkins y las herramientas de automatización dentro de un flujo de trabajo DevOps.
